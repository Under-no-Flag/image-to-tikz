# 可迁移的复刻流程

本文件总结跨图类型的决策，不提供针对某张图的固定坐标或模板答案。Scene 是本次读图的结果；不要将测试案例的节点、文字、裁切坐标或拓扑复制进新任务再强行套图。

## 首次构建前

1. **确定范围与尺度。** 整张图还是某个 Figure？裁切后重新记录坐标空间与哈希。指定输出物理宽度；像素尺寸、字号和笔宽都换算到同一个尺度。
2. **建立组件清单。** 区分文字、容器、特征图、投影面、操作符、箭头和独立 icon。按行列、面板和父子组建相对布局；尺寸组只合并同角色且同尺寸的组件。
3. **读取文字证据。** 一次 PaddleOCR 整图识别；若只返回图注或 image 块，先试一个紧裁文字区和关闭版面分析，成功后再补必要区域。缓存同图同参数结果。列出 OCR 支持、人工补录和未辨认内容。
4. **建立样式表。** 按角色列字体、字号、字重、线宽、线色、虚实、箭头头部和填充。放大核对最长标签、浅灰线和局部加粗；不要把字体墨量当成笔宽，也不要由“标题”推断粗体。
5. **逐条记录连接。** 记录源端点、目标端点、折点、方向与遮挡。普通线、箭头、双向箭头、三角块和投影射线分开。交叉不等于汇合；相邻组件不等于连接；不按模型知识补全图中没有的线。

## 按图形选择表示

| 可见结构 | 表示与核对重点 |
|---|---|
| 特征图堆叠 | `feature-stack`；可见片数、间距、叠放方向和前后关系。通道标签与可见片数分开。 |
| 厚块/倾斜片 | `slab`；高宽深比例及侧面，不能改成等大流程框。 |
| 魔方网格/渐变张量 | `cuboid`；三面、网格数、深度投影、各面明暗；不要生成位图张量。 |
| 斜投影平面 | `grid-plane`；四角与格线，以组件局部坐标连接。 |
| 散点/小网络 | `motif`；保留可见节点与主要边，模糊细节明确近似范围。 |
| 固定比例菱形/宽箭头 | `polygon` + 独立文字；文字撑大形状时不牺牲轮廓比例。 |
| 曲线/残差/反馈 | 节点锚点、相对折点或三次曲线；放大确认端点和箭头，不凭名称补画。 |
| 独立语义 icon | 用户要求且 GPT image_gen 可用时生成透明 PNG；保留提示词、哈希、裁切坐标，声明该资产是栅格。 |

## 编译后的高收益检查

优先检查：OCR 漏识标签 → 小间隙与线端点 → 实际文字边界与换行 → 特征图比例/堆叠 → 线宽/灰度/字重 → 组间距。源码结构校验不能证明这些图像层面的忠实度。

先留存首次成功渲染，再修正已看到的问题；保留真实的编译失败和 OCR 请求次数。不得从最后一版倒推首次成功率。不能用聚合 OCR 块全部映射，宣称全部字符都被 OCR 识别。

只看图片完成重建并冻结后，才可以读取目标原始 TikZ。后验发现错误时保留原快照、明确撤销原验收并另建修订版。源码辅助版在展示和交付中始终标注，不混入图片盲测成绩。

## 换图时的边界

流程和图元可复用，不意味着所有新图都能自动或一次完美复刻。新图仍需 agent 读图、选样式、填写 Scene 和视觉核对。无法可靠恢复的细节写入 `unresolved` 或近似说明，不能用案例名称触发特例。新增能力应以参数化图元/样式/校验表达，并用不同尺寸、节点数或方向的合成场景验证通用性。
